# 星际温室

一款无需安装依赖的单人增量游戏。点击星核收集星光，购买自动生产设施，解锁升级，并在累计 5,000 星光后重生获取永久加成。

## 本地运行

```sh
npm start
```

打开 <http://127.0.0.1:4173/>。也可以使用其他静态文件服务器托管本目录。浏览器必须通过 HTTP(S) 打开页面，才能正常加载 ES 模块。

## 游戏规则

- 光芽、轨道集光器、星核反应堆自动生产星光，购买价格逐个上涨 15%。
- 可一次购买 1 个、10 个或当前能买的最大数量。
- 升级只在当前轮次生效；重生得到的星种永久增加手动与自动产量，每颗星种增加 100%。
- 存档保存在当前浏览器的 `localStorage`。离线收益最多计算 8 小时；清除浏览器站点数据会清除存档。
- 重置所有进度和重生前都会显示确认弹窗。

## 验证

```sh
npm test
node --check app.mjs
python3 -m unittest test_server.py
```

## 与 Awesome Deploy 的关系

仓库包含 `schemaVersion: 2` 的 `awesome.yaml`、`Dockerfile` 和 `/healthz` 服务。`stgreen` 是清单中的候选子域名，实际可用性须由平台受理时确认。容器只复制游戏页面和服务器文件；本地验证可运行 `PORT=8080 python3 server.py`。

这个游戏的存档保存在浏览器 `localStorage`，部署不需要新增游戏登录、数据库、服务器数据卷或密钥。人工部署可由有权限的操作者在 Awesome Deploy 控制台选择项目并提交本仓库；脚本或 CI 部署可使用平台的普通自动化凭证和固定幂等键。只有其他可信后端需要按实际登录用户代为申请部署时，才需要 skill 的共享会话与同组接入流程。凭证不放进游戏代码或仓库。当前只完成仓库准备，尚未提交真实部署申请，也未验证远端构建或上线。更换域名或清除站点数据可能使原浏览器存档不可用。
